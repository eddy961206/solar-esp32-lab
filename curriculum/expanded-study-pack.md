# 확장 학습팩

이 문서는 기존 3권 요약을 더 길게 읽기 위한 확장판이다. 목표는 책처럼 차분히 읽고, 실험처럼 바로 해보고, 전기기사 공부처럼 문제로 바꾸는 것이다.

## 1부. 전기를 무서워하지 않되 가볍게 보지 않기

전기는 눈에 보이지 않는다. 그래서 초심자는 두 가지 실수를 하기 쉽다. 하나는 너무 무서워해서 아무것도 못 하는 것이고, 다른 하나는 낮은 전압이라는 말만 믿고 아무 배선이나 연결하는 것이다.

이 저장소의 태도는 가운데다. 낮은 전압 DC 실험으로 시작하되, 항상 전류, 전력, 발열, 단락 가능성을 본다.

전압은 두 점 사이의 차이다. 그래서 멀티미터에는 빨간 프로브와 검은 프로브가 있다. 검은 프로브를 어디에 대느냐가 기준점이 된다. 태양광 패널의 마이너스에 검은 프로브를 대고 플러스에 빨간 프로브를 대면 양수 전압이 나온다. 반대로 대면 음수 전압이 나온다.

전류는 닫힌 길에서만 흐른다. 패널에 아무것도 연결하지 않고 전압만 재면 개방전압을 보는 것이다. 이 상태에서는 전압은 보여도 실제로 일을 하는 전력은 거의 없다. 저항을 연결하면 길이 닫히고 전류가 흐른다.

저항은 초심자에게 가장 좋은 부하다. 계산이 쉽고, 전류를 제한하고, 발열로 전력의 존재를 보여준다.

```text
I = V / R
P = V * I
P = V^2 / R
```

예를 들어 100옴 저항에 5V가 걸리면 전류는 0.05A, 전력은 0.25W다. 10옴 저항에 5V가 걸리면 전류는 0.5A, 전력은 2.5W다. 전압은 같은데 저항이 작아지면 전류와 발열이 훨씬 커진다.

초심자용 실험 순서:

1. 패널 개방전압 측정
2. 100옴 저항 연결
3. 47옴 저항 연결
4. 20옴 저항 연결
5. 10옴 저항은 짧게만 실험

각 실험에서 기록할 것:

```text
시간, 날씨, 위치, 패널 방향, 저항값, 전압, 계산 전류, 계산 전력, 발열 느낌, 이상한 점
```

## 2부. 멀티미터는 모드가 절반이다

멀티미터 사고는 대개 기계가 나빠서 생기지 않는다. 모드와 리드 위치가 틀려서 생긴다.

전압 측정 기본:

```text
검은 리드: COM
빨간 리드: V옴
다이얼: DC V
연결: 회로 양끝에 병렬
```

전류 측정 기본:

```text
회로를 끊고 직렬로 넣어야 함
리드 위치가 바뀔 수 있음
초심자는 INA219로 대신하는 편이 안전함
```

저항 측정 기본:

```text
전원을 끄고 측정
회로 안에 병렬 경로가 있으면 값이 다르게 나올 수 있음
```

멈춰야 하는 상황:

```text
전압을 재려는데 빨간 리드가 A/mA 단자에 있음
전류 모드로 패널 +와 -에 프로브를 댐
저항이나 전선이 뜨거움
타는 냄새가 남
값이 예상과 크게 다르고 이유를 설명할 수 없음
```

## 3부. ESP32는 전기를 먹는 장치가 아니라 숫자를 읽는 장치로 시작한다

태양광 프로젝트를 처음 보면 패널로 ESP32를 켜고 싶어진다. 하지만 첫 목표는 전원 자립이 아니다. 첫 목표는 측정이다.

기본 구조:

```text
ESP32: USB 전원
태양광 패널: 측정 대상
INA219: 패널 전압/전류 측정
BH1750: 빛의 밝기 측정
시멘트 저항: 안전한 부하
```

ESP32에서 가장 먼저 익힐 것:

- 코드 업로드
- Serial 출력
- I2C scanner
- 센서 하나씩 읽기
- 센서 두 개 같이 읽기
- CSV 형태로 출력

I2C 기본 배선:

```text
ESP32 3V3 -> 센서 VCC
ESP32 GND -> 센서 GND
ESP32 GPIO21 -> SDA
ESP32 GPIO22 -> SCL
```

I2C scanner가 센서를 못 찾으면 라이브러리보다 배선을 먼저 본다.

확인 순서:

1. 3.3V 전원이 들어갔는가
2. GND가 공유됐는가
3. SDA/SCL이 뒤집히지 않았는가
4. 주소가 충돌하지 않는가
5. 센서를 하나씩 꽂으면 보이는가

## 4부. 로그는 실험의 기억이다

한 번 본 숫자는 금방 사라진다. CSV로 남긴 숫자는 나중에 그래프와 문제로 바뀐다.

추천 CSV:

```text
timestamp,voltage_v,current_ma,power_mw,lux,load_ohm,panel_angle_deg,note
```

로그를 쌓으면 물어볼 수 있는 질문:

- 하루 중 전력이 가장 높았던 시간은 언제인가?
- 조도는 높은데 전력은 낮은 순간이 있었는가?
- 어떤 저항에서 전력이 가장 컸는가?
- 패널 각도와 전력은 어떤 관계가 있는가?
- 창문 안쪽과 바깥쪽은 얼마나 다른가?

그래프 추천:

| 그래프 | x축 | y축 | 배우는 것 |
|---|---|---|---|
| 하루 전력 | 시간 | 전력 | 시간대 변화 |
| 조도-전력 | lux | mW | 빛과 발전 관계 |
| 저항별 전력 | 저항 | 전력 | 부하와 최대전력 |
| 전압-전류 | 전압 | 전류 | I-V 곡선 |

## 5부. 태양광 패널은 이상적인 전압원이 아니다

태양광 패널은 햇빛과 부하에 따라 동작점이 계속 바뀐다.

개방 상태:

```text
전압은 높게 보임
전류는 거의 없음
전력은 거의 없음
```

너무 무거운 부하:

```text
전류를 많이 요구함
패널 전압이 내려감
전력이 오히려 줄 수 있음
```

중간 지점:

```text
전압과 전류의 곱이 최대
최대전력점 MPP
```

MPPT는 어려운 말이지만 초심자식으로는 “패널이 가장 힘 좋게 일하는 지점을 찾는 일”이다. 처음에는 회로로 자동 추적하지 말고, 저항을 바꿔가며 손으로 찾아본다.

## 6부. 배터리는 나중에 한다

태양광 프로젝트가 재미있어질수록 배터리를 붙이고 싶어진다. 하지만 리튬 배터리는 초심자 실험에서 가장 조심해야 할 부품이다.

배터리 실험 전에 알아야 할 것:

- 충전 전압
- 충전 전류
- 보호회로
- 과충전
- 과방전
- 발열
- 물리적 손상
- 무인 운전 위험

이 저장소의 기본 원칙:

```text
충전 모듈 없이 리튬 배터리를 충전하지 않는다.
보호회로 없는 셀은 쓰지 않는다.
부풀거나 손상된 배터리는 쓰지 않는다.
브레드보드로 큰 전류 경로를 만들지 않는다.
무인 충전은 하지 않는다.
```

배터리는 금지라기보다 후반 설계 과제다. 먼저 전압, 전류, 전력, 하루 Wh를 계산할 수 있어야 한다.

## 7부. 전기기사 공부와 연결하기

전기기사 공부가 막막한 이유는 개념이 큰 설비 단위로 나오기 때문이다. 하지만 작은 실험으로 번역하면 잡힌다.

| 전기기사 과목 | 작은 실험 번역 |
|---|---|
| 전기자기학 | 전압은 전위차, 커패시터는 전하 저장 |
| 전력공학 | 태양광 패널은 작은 발전원 |
| 전기기기 | 저항 발열은 손실과 정격 |
| 회로이론 | 저항 부하, 직렬/병렬, 전력 계산 |
| 제어공학 | 센서값에 따라 측정 주기나 LED를 제어 |
| 전기설비기술기준 | 접속, 정격, 보호, 차단, 점검 |
| 실기 | 측정값 표, 계산 과정, 안전 판단 |

실험을 문제로 바꾸는 예:

```text
문제:
47옴 5W 저항에 4.6V가 걸렸다.
전류, 소비전력, 정격 대비 사용률을 구하고 점검 항목을 쓰시오.

풀이:
I = V/R = 4.6/47 = 0.0979A = 97.9mA
P = V^2/R = 21.16/47 = 0.450W
정격 대비 = 0.450/5*100 = 9.0%
점검 = 발열, 접속 상태, 주변 가연물, 전선 허용전류
```

좋은 답안은 계산에서 끝나지 않는다. 계산 뒤에 “정격상 여유는 있지만 실제 발열과 접속부는 확인한다” 같은 판단이 붙어야 한다.
