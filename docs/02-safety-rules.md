# 02. 안전 규칙

## 반드시 지킬 규칙

1. 사용자는 처음에는 DC 전압 측정만 한다.
2. 사용자는 멀티미터의 빨간 리드를 평소에는 VΩ 단자에 꽂아 둔다.
3. 사용자는 멀티미터를 A/mA/10A 모드로 놓고 전압을 재지 않는다.
4. 사용자는 태양광 패널 앞면을 가리거나 어두운 상태에서 배선을 만진다.
5. 사용자는 패널의 빨강(+) 전선과 검정(-) 전선을 서로 닿게 하지 않는다.
6. 사용자는 시멘트 저항이 뜨거워질 수 있다는 점을 기억한다.
7. 사용자는 배터리, 보조배터리, 리튬셀을 아직 연결하지 않는다.
8. 사용자는 220V 콘센트 쪽은 건드리지 않는다.

## 멈춰야 하는 경우

- 멀티미터 값이 이상하게 0 또는 음수만 나온다.
- 프로브나 전선이 너무 뜨겁다.
- 타는 냄새가 난다.
- 연결한 순간 불꽃이 보인다.
- 무엇을 어디에 연결했는지 스스로 설명할 수 없다.
