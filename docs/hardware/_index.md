|------|------|
| `0x40` | INA219 (기본) |
| `0x23` | BH1750 (ADDR=GND) |
| `0x5C` | BH1750 (ADDR=VCC, 대체 주소) |

## 최대 위험 주의사항 (AI 에이전트 참고)

> [!CAUTION]
> 1. **ESP32 GPIO에 5V 직접 연결 금지** → 칩 손상
> 2. **BH1750에 5V 공급 금지** → 센서 파손
> 3. **멀티미터로 전류 측정 시 직렬 연결**, 병렬 연결 시 퓨즈 단선
> 4. **10Ω 시멘트 저항을 직사광선 패널에 단독 연결 금지** → 정격 전력 초과 발열
> 5. **패널 극성 반드시 확인** (적색=+, 흑색=−)
