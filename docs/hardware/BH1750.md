# BH1750 — 조도(밝기) 센서 모듈

## 📐 전기적 특성

| 항목 | 값 |
|------|----|
| 동작 전압 (VCC) | 2.4 – 3.6 V (3.3V 권장) |
| 측정 범위 | **1 – 65,535 lux** |
| 인터페이스 | **I2C** |
| 기본 I2C 주소 | **0x23** (ADDR=GND) |
| 대체 I2C 주소 | **0x5C** (ADDR=VCC) |

## 📏 측정 모드

| 모드 | 분해능 | 측정 시간 |
|------|--------|-----------|
| Low Resolution | 4 lux | ~16 ms |
| High Resolution | **1 lux** | ~120 ms |
| High Resolution 2 | **0.5 lux** | ~120 ms |

> 이 프로젝트에서는 **High Resolution 모드** 사용 권장 (태양광 조도 정밀 측정).

## 📦 모듈 핀 설명

| 핀 | 설명 |
|----|------|
| VCC | 3.3V 입력 (ESP32의 3.3V 핀 연결) |
| GND | 접지 |
| SDA | I2C 데이터 (ESP32: GPIO 21, INA219와 공유 가능) |
| SCL | I2C 클럭 (ESP32: GPIO 22, INA219와 공유 가능) |
| ADDR | 주소 설정: GND → 0x23, VCC → 0x5C |

## ⚠️ 주의사항

1. **5V 비허용**: BH1750은 최대 3.6V. ESP32의 3.3V 핀 사용, **5V 연결 시 파손**.
2. **INA219와 I2C 공유 가능**: 두 센서 모두 I2C라 GPIO21/22 하나의 버스에 연결 가능. 주소가 다름(0x40 vs 0x23).
3. **빛 차단 실험**: 센서를 손으로 가리면 0~10 lux 수준. 정상 동작 확인 방법으로 활용.
4. **직사광선 포화**: 직사광선(>65,535 lux) 조건에서는 최대값 반환. 실내 창가는 1,000~10,000 lux 수준이므로 문제없음.
5. **측정 대기 시간**: High Resolution 모드에서 측정 후 최소 120ms 대기 후 값 읽기.

## 🔌 ESP32 연결도 (INA219와 I2C 공유)

```
ESP32          BH1750 모듈     INA219 모듈
3.3V   ──┬──► VCC            VCC
GND    ──┼──► GND            GND
GPIO21 ──┼──► SDA            SDA    ← I2C 버스 공유
GPIO22 ──┼──► SCL            SCL    ← I2C 버스 공유
         └──► ADDR → GND (주소 0x23)
```

## 💻 아두이노 라이브러리

- 권장 라이브러리: `BH1750` by Christopher Laws (Library Manager에서 설치)
- 기본 코드:
```cpp
#include <Wire.h>
#include <BH1750.h>

BH1750 lightMeter;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  lightMeter.begin(); // 기본 주소 0x23, High Resolution 모드
}

void loop() {
  float lux = lightMeter.readLightLevel();
  Serial.printf("Illuminance: %.1f lux\n", lux);
  delay(1000);
}
```
