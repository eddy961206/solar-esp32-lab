# INA219 — 전류/전압 센서 모듈

## 📐 전기적 특성

| 항목 | 값 |
|------|----|
| 동작 전압 (VCC) | 3.0 – 5.5 V |
| 측정 가능 버스 전압 | 0 – **26 V** |
| 최대 샨트 전압 | ±320 mV |
| 최대 전류 (기본 샨트 0.1Ω) | **3.2 A** |
| 전류 분해능 | 0.8 mA |
| 전압 분해능 | 4 mV |
| 인터페이스 | **I2C** |
| 기본 I2C 주소 | **0x40** |

## 📦 모듈 핀 설명

| 핀 | 설명 |
|----|------|
| VCC | 3.3V 또는 5V 입력 (ESP32의 3.3V 핀 연결) |
| GND | 접지 |
| SDA | I2C 데이터 (ESP32: GPIO 21) |
| SCL | I2C 클럭 (ESP32: GPIO 22) |
| VIN+ | 측정 회로의 (+) 입력 (전원 측) |
| VIN− | 측정 회로의 (−) 출력 (부하 측) |

## ⚠️ 주의사항

1. **직렬 연결 필수**: INA219는 **전원선에 직렬**로 삽입해야 전류를 측정할 수 있음. 병렬 연결하면 측정 안 됨.
2. **VIN+ → 전원, VIN− → 부하 방향 주의**: 반대로 연결하면 음수 전류가 측정됨 (망가지지는 않음).
3. **최대 버스 전압 26V**: SNP-5MA Voc(10.8V)는 안전 범위 이내.
4. **샨트 저항 발열**: 3A 이상 지속 전류 시 샨트 저항 발열 주의 (이 프로젝트의 Isc 0.61A는 문제없음).
5. **I2C 주소 충돌**: 복수 INA219 사용 시 A0/A1 핀으로 주소 변경 필요 (0x40~0x4F).
6. **풀업 저항**: 대부분의 모듈에 4.7kΩ 풀업 저항 내장. 추가 풀업 불필요.

## 🔌 ESP32 연결도 (이 프로젝트 기준)

```
ESP32          INA219 모듈
3.3V   ──────► VCC
GND    ──────► GND
GPIO21 ──────► SDA
GPIO22 ──────► SCL

SNP-5MA (+) ─► VIN+
              VIN− ─► 부하(저항) ─► SNP-5MA (−)
```

## 💻 아두이노 라이브러리

- 권장 라이브러리: `Adafruit INA219` (Library Manager에서 설치)
- 기본 코드:
```cpp
#include <Wire.h>
#include <Adafruit_INA219.h>

Adafruit_INA219 ina219;

void setup() {
  Serial.begin(115200);
  ina219.begin(); // 기본 주소 0x40
}

void loop() {
  float voltage = ina219.getBusVoltage_V();
  float current = ina219.getCurrent_mA();
  float power   = ina219.getPower_mW();
  Serial.printf("V=%.2fV, I=%.1fmA, P=%.1fmW\n", voltage, current, power);
  delay(1000);
}
```
