## 📦 단자(포트) 설명

| 단자 | 용도 |
|------|------|
| `COM` | 공통 (−) — 항상 흑색 리드 연결 |
| `VΩmA` | 전압/저항/소전류 측정 — 적색 리드 연결 |
| `10A` | **10A 전류 측정 전용** — 적색 리드 연결 |

## ⚠️ 주의사항

1. **10A 단자 전용 사용**: 10A 레인지 측정 시 반드시 적색 리드를 `10A` 단자로 이동. `VΩmA`에 꽂은 채로 10A 레인지 선택 시 퓨즈 즉시 단선.
2. **전류 측정은 직렬 연결**: 전류계는 회로에 직렬로 연결. 전압을 재듯 병렬로 연결하면 단락 발생 → 퓨즈 단선 또는 회로 손상.
3. **DC/AC 구분**: 태양광 패널은 항상 DC. AC 레인지로 측정하면 0 또는 이상한 값 표시.
4. **CAT II 600V**: 상용 전원(가정 콘센트 220V AC)까지 안전하게 측정 가능한 등급. 이 프로젝트(최대 10.8V DC)는 충분히 안전 범위 이내.
5. **배터리 소모**: 9V 배터리 소모 시 측정값 부정확. 디스플레이 흐림 또는 "BAT" 표시 시 교체.
6. **리드 꽂는 순서**: 측정 전 리드를 먼저 단자에 꽂고, 이후 측정 대상에 접촉. 해제 시 반대 순서.

## 🔌 태양광 패널 전압 측정 방법

```
멀티미터 설정: DCV 20V 레인지 (또는 AUTO 레인지)

```
