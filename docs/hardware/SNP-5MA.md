# SNP-5MA — 태양광 패널 (5W, 6V 배터리 충전용)

## ⚠️ 주의사항

1. **극성 확인 필수**: 적색 = (+), 흑색 = (−). 역접속 시 INA219, ESP32 손상 위험.
2. **개방 전압 주의**: 햇빛 아래 출력단 개방 시 Voc ≈ 10.8V. INA219의 정격 전압(26V) 이내이지만, 브레드보드 점퍼선이 빠지면 단자가 노출되므로 주의.
3. **단락 금지**: 양극과 음극을 직접 단락(short)하면 Isc ≈ 0.61A가 흘러 패널 및 연결선 손상.
4. **실내 조건**: 창가에서 실험 시 Voc는 3~6V, Isc는 0.05~0.2A 수준으로 대폭 낮아짐. 이는 정상임.
5. **6V 충전 전용**: 이 패널의 Vmp(9V)는 6V 배터리 충전에 최적화. 12V 배터리에는 부적합.

## 🔌 INA219와 연결 시 주의

```
태양광 패널 (+) → INA219 VIN+ → 부하(저항 등) → INA219 VIN- → 태양광 패널 (-)
```

- INA219는 **직렬(series)** 로 연결해야 전류 측정 가능.
- 전압 측정은 INA219가 VIN+ 와 GND 사이를 측정함.
- 샨트 저항에 의한 전압 강하(최대 0.32V)는 이 패널에서 무시 가능한 수준.
