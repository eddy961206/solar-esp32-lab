- 숫숫 점퍼선
- 암암 점퍼선

- 악어클립 테스트 리드

## 각 부품의 쉬운 역할

- 태양광 패널: 전기를 만드는 물건
- 멀티미터: 지금 전압이 몇 V인지 보는 물건
- INA219: 전압/전류를 ESP32가 읽게 해 주는 계량기
- BH1750: 밝기를 숫자로 보는 센서
- ESP32: 센서 숫자를 읽어서 컴퓨터로 보내는 작은 컴퓨터
- 브레드보드: 납땜 없이 꽂아보는 판
- 시멘트 저항: 전기를 안전하게 먹는 가짜 전기제품
