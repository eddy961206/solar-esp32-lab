# 04. 1일차 - 패널과 멀티미터만으로 전압 재기

## 패널 정션박스 기준

- 오른쪽 위 나사 단자 = 플러스(+)
- 왼쪽 위 나사 단자 = 마이너스(-)
- 아래쪽 넓은 금속판 = 출력 단자가 아님
- 위쪽 검은 원통 부품 = 보호용 부품이므로 건드리지 않음

## 멀티미터 준비

1. 사용자는 검은 리드를 COM에 꽂는다.
2. 사용자는 빨간 리드를 VΩ에 꽂는다.
3. 사용자는 다이얼을 DC 전압(V, 직선 표시) 쪽으로 맞춘다.
4. 사용자는 A, mA, 10A 쪽으로 다이얼을 돌리지 않는다.

## 측정 방법

1. 사용자는 패널 앞면을 잠깐 가린다.
2. 사용자는 검은 프로브를 왼쪽 위 나사에 댄다.
3. 사용자는 빨간 프로브를 오른쪽 위 나사에 댄다.
4. 사용자는 패널 앞면의 가림을 치운다.
5. 사용자는 밝은 창가 또는 직사광선 쪽으로 패널을 향하게 한다.
6. 사용자는 멀티미터 숫자를 읽는다.

## 기록 양식

- 시간
- 위치
- 밝기 상태
- 전압(V)
