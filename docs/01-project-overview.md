# 01. 프로젝트 개요

## 지금 만들려는 것

태양광 패널 → 전기 발생 → 전압/전류 측정 → ESP32가 숫자 읽기 → 맥미니/우분투에서 로그 저장

## 1차 목표

1. 사용자는 패널 전압을 재본다.
2. 사용자는 패널에 저항을 연결해 본다.
3. 사용자는 INA219로 전압/전류를 읽는다.
4. 사용자는 BH1750으로 밝기를 읽는다.
5. 사용자는 ESP32 시리얼 모니터에 값을 출력한다.

## 지금 하지 않는 것

- 리튬 배터리 충전
- 220V 연결
- 인버터 사용
- 장시간 무인 충전
- 태양광 패널을 ESP32 전원으로 직접 쓰기

## 지금 가장 중요한 생각

사용자는 처음부터 전기를 많이 모으는 사람이 아니라, 전기를 정확하게 보는 사람이 된다.
